Como este projeto foi feito

Da fonte oficial ao gráfico

Arquitetura medalhão no Databricks: o dado bruto entra como veio (bronze), é limpo e tipado (silver) e vira uma tabela pronta para o gráfico (gold). O mesmo SQL roda no Databricks, no Snowflake e no DuckDB, que é o plano B quando a nuvem falha.

01 · extração

APIs oficiais

Python baixa BCB (SGS 1619 e 433), ANP, FipeZAP, IPEA e The Economist, com retentativa, manifesto (origem, linhas, hash) e snapshot de reserva.

02 · bronze

Volume + Delta

Os arquivos sobem para um Volume do Unity Catalog pela Files API e viram tabelas Delta com read_files.

03 · silver

Limpo e tipado

Um grão por tabela (mês ou ano). Moedas pré-Real descartadas; IPCA composto mês a mês.

04 · gold + testes

Pronto para o BI

gold_poder_compra_anual, _mensal e gold_qualidade. O pipeline para se um teste falhar, e o pytest confere contra valores checados à mão.
